# مخطط العوالم المتقدم (Advanced AI World Planner)

يفهم المخطط الأوصاف الطبيعية المعقّدة بالعربية والإنجليزية — لا الكلمات المفتاحية
المسبقة فقط — ويحوّلها إلى **مواصفات عالم منظّمة** (`WorldSpec`) ثم إلى **خطة تنفيذ
كاملة** تُنجز قبل إنشاء أي عنصر. بعدها تتولّى أنظمة التوليد القائمة البناء كما
هي، بلا تعديل في سلوكها.

- الشيفرة: `src/modules/planner/` (12 وحدة، ~4560 سطراً)
- الاختبارات: 12 ملفاً شقيقاً، **248 اختباراً** (`npx vitest run src/modules/planner`)
- الواجهة: `src/modules/editor/panels/AiPanel.tsx`
- الخادم المحلي: `world-builder-server.py` (مسار `/api/local-llm` اختياري)
- وثيقة صيغة العالم: [`WORLDPLAN.md`](./WORLDPLAN.md) · المعمارية: [`ARCHITECTURE.md`](./ARCHITECTURE.md)

---

## 1. المبادئ الأربعة

| المبدأ | ماذا يعني عملياً |
| --- | --- |
| **الخطة قبل التوليد** | لا يُنشأ أي عنصر قبل اكتمال `WorldSpec` وخطة الـ16 خطوة ونجاح `preflight`. لا توليد جزئي ثم قرار. |
| **الحتمي أولاً** | الطبقة الافتراضية قواعدية تماماً، بلا إنترنت وبلا مفاتيح API. النموذج اللغوي المحلي **اختياري** ويسدّ النقص فقط. |
| **لا كسر للأنظمة القائمة** | المخطّط يغلف `interpretPromptLocally` و`generateWorldPlanWithReport` و`validateScenePlan` ولا يستبدلها. المفسّر القديم يبقى الطبقة صفر وهو المرجع فيما يفهمه. |
| **لا تخمين صامت** | كل تناقض يُسأل عنه، وكل ما لا يمكن بناؤه يُعلن في تحذير عربي، وكل ما يقلمه المخطط يُذكر بالسبب. |

## 2. خط الأنابيب

```
الوصف (عربي/إنجليزي/مختلط)
  ├─ 0. interpretPromptLocally        المفسّر القائم — يبقى المرجع (طبقة صفر)
  ├─ 1. normalize + lexicon           تطبيع النص + معجم ثنائي اللغة
  ├─ 2. extractFrames                 عناصر، أعداد، صفات، أحجام، علاقات، نفي، أوقات
  ├─ 3. solveSpec                     قيود ← WorldSpec (أبعاد، تضاريس، مناطق، مبانٍ، ميزانيات)
  ├─ 4. detectContradictions          أسئلة حاجبة واستشارية + تطبيق الأجوبة
  ├─ 5. النموذج المحلي (اختياري)       سدّ النقص فقط، مُتحقَّق منه بمخطط صارم
  ├─ 6. buildExecutionPlan            16 خطوة مرتّبة + تبعيات + preflight
  │                                   ── لا شيء يُولَّد قبل هذه النقطة ──
  ├─ 7. generateWorldPlanWithReport   تضاريس أولية (الأعداد صفر) لعينة الارتفاعات
  ├─ 8. resolveLayout                 العلاقات ← إحداثيات على التضاريس الفعلية
  ├─ 9. generateWorldPlanWithReport   التوليد القائم نفسه، بنيةً من المواصفات
  ├─ 10. applySpecToPlan              طرق وجسور، حوض بحيرة، مواد، إضاءة، جو، مناطق
  └─ 11. validateScenePlan            التحقق القائم، مع إسقاط ما يمكن استرداده
```

`planWorld()` تُنتج الخطوات 0–6 (بلا أي عنصر)، و`executePlannerResult()` تُنتج 7–11،
و`planAndBuildWorld()` تجمع الاثنين.

## 3. الوحدات

| الملف | المسؤولية |
| --- | --- |
| `normalize.ts` | تطبيع النص (تشكيل، همزات، tatweel، أرقام عربية)، التجزئة، كشف اللغة، الأعداد والمضاعفات (`دستة`=12)، النفي ونطاقه، `scanTerms`. |
| `lexicon.ts` | معجم ثنائي اللغة مولّد: كل مصطلح إنجليزي يقابله عربي مع جمع سالم ومكسّر ومثنّى وتنوين. الفئات: تضاريس، بيئات، مبانٍ، نباتات، حيوانات، مواد، طرز، طقس، أوقات، مقاييس، كثافة. |
| `frames.ts` | استخراج «الإطارات»: العناصر وأعدادها، إسناد الصفات والأحجام والمقاييس إلى الاسم الصحيح (سلاسل الصفات)، 18 رابطاً مكانياً، النفي ونطاقه، أوقات اليوم، التلميحات. |
| `worldSpec.ts` | أنواع `WorldSpec` و`ExecutionPlan`، مخطط zod الصارم `llmEnrichmentSchema` لإجابات النموذج، `worldSpecGuard`، `pathStyleFor`. |
| `contradictions.ts` | 11 قاعدة تناقض + `resolveWithAnswers`. |
| `solve.ts` | حلّ القيود: أبعاد، تضاريس، بحيرة، بيئات، مناطق، مبانٍ، عناصر، مواد، إضاءة، جو، علاقات، نفي، ميزانيات، `clampToBudget`، `intentFromSpec`. |
| `executionPlan.ts` | الخطوات الـ16، الترتيب الطوبولوجي، الميزانيات، `preflight` (أخطاء حاجبة وتحذيرات)، `countRequested`. |
| `layout.ts` | `WorldLayout`: عيّنات على التضاريس الفعلية (أعلى/أخفض نقطة، حافة الماء، حلقة، خط، نثر، سلسلة)، و`resolveLayout` لتحويل العلاقات إلى إحداثيات. |
| `realize.ts` | `applySpecToPlan` و`applySpecToShell`: ما لا يحمله `WorldIntent` (طرق، جسور، حوض بحيرة، مواد، إضاءة، جو، وسم المناطق). |
| `backends.ts` | `ruleBackend` (دائماً متاح) و`createLocalLlmBackend` (اختياري) و`mergeEnrichment` و`enrichmentGaps`. |
| `planner.ts` | الواجهة العامة: `planWorld`، `executePlannerResult`، `planAndBuildWorld`، `PlannerBlockedError`. |
| `specSummary.ts` | العرض العربي: `describeSpec` (14 قسماً)، `describeExecution`، `summarizeSpec`، `describePreflight`. |

## 4. مواصفات العالم المنظّمة (`WorldSpec`)

| القسم | المحتوى |
| --- | --- |
| `dimensions` | `size` (32–512)، `resolution` (16–256)، `scale`، `source` (`scale-word`/`explicit`/`default`)، `areaUnitsSquared`. |
| `terrain` | `style` (10 أشكال)، `heightScale`، `roughness`، `water`، `lake{x,z,radius,depth}`، `river{axis,width,excavates:false}`. |
| `biomes` / `regions` | مناطق حيوية بأوزان، ومناطق منطقية (`circle`/`ring`/`rect`/`band`) بمحدّدات اتجاهية وأعضاء. |
| `buildings` / `assets` | `kind` أو `assetId`، العدد، الطراز المعماري، المادة، الحجم، المنطقة، `placement{strategy,anchor,positions}`، `realized`. |
| `counts` | نثر النباتات والصخور والمباني والفوانيس، محسوباً من البيئة والمقياس والكثافة. |
| `materials` / `lighting` / `environment` | لوح وألوان الجدران والأسقف والخشونة والمعدنية؛ الوقت ومعاملات الشمس؛ الطقس والفصل والضباب والألوان والأسلوب والكثافة. |
| `relations` | 16 مسنداً مكانياً مع الموضوع والمجرور والوسيلة والحالة (`pending`/`resolved`/`unsupported`) والإحداثيات. |
| `negations` / `animals` / `clarifications` / `notices` | التعليمات السالبة ونطاقها، الحيوانات (موثّقة غير قابلة للبناء بعد)، الأسئلة، الإشعارات العربية. |
| `positions` | إحداثيات كل عنصر بعد `resolveLayout` (≤400 لكل مفتاح). |
| `execution` | الخطوات، الترتيب، الميزانيات، `preflight`. |
| `cues` / `tier` / `offline` / `language` / `specVersion` / `seed` | ما فُهم من الوصف، الطبقة المستخدمة، عدم الاتصال، اللغة، الإصدار، البذرة. |

## 5. الفهم اللغوي

### العلاقات المكانية (18 رابطاً)

`فوق/على قمة` · `تحت/عند سفح` · `تحيط بـ/حول` · `محاطة بـ` · `تربطها/متصلة بـ` ·
`يعبر/خلال/عبر` · `يمتد فوق` · `بين` · `على امتداد/بمحاذاة` · `داخل/وسط` · `مقابل/يطل على` ·
`بجانب/بجوار/قرب` · `يسار` · `يمين` · `أمام` · `خلف` (+ مرادفاتها الإنجليزية).

لكل رابط موضوع ومجرور ووسيلة. «البيوت تربطها طرق ترابية» ⇒ `connected-by` بين البيوت
عبر «طريق»، و`realize.ts` يمدّ شريط طريق يتبع التضاريس بين **المواضع الفعلية** التي
انتهى إليها المولّد، لا المواضع المخططة فقط.

### المقياس والكثافة والنِّسب

- كلمة مقياس متصلة باسم عادي تصف ذلك الاسم: «قلعة كبيرة» ⇒ `scaleFromObject`.
- كلمة مقياس متصلة بنطاق العالم تصف العالم: «عالم واسع»، «a vast desert» ⇒ `dimensions.scale`.
- اتجاه الإسناد يتبع اللغة: في العربية الاسم قبل الصفة، وفي الإنجليزية بعدها.
- الأساليب المعمارية (`قروسطي`، `حديث`…) والمواد (`حجر`، `خشب`، `طوب`…) تُسند إلى
  المبنى الذي تلصق به، لا إلى أقرب اسم جبل أو شجرة (سلاسل الصفات تُحلّ بالترتيب).

### التعليمات السالبة

«بدون أشجار» ⇒ نفي عام يُصفّر النثر ويحذف العناصر النباتية.
«بدون أشجار نخيل» ⇒ نفي **مخصّص بالنوع**: يُحذف النخيل وحده وتبقى الغابة خضراء،
مع إشعار عربي يشرح ذلك. النفي المسحوب («لا أريد… بل أريد») والتضييق على الفئات
(`NEGATION_SCOPE_CATEGORIES`) يمنعان النفي الزائف، مثل «صغير» التي تحوي «غير».

### ما لا يفعله المخطط

لا يخمّن حيوانات: تُسجَّل في `WorldSpec` مع عددها وتسميتها العربية، ويُعلن صراحة أنه
لا يوجد باني إجرائي محلي لها بعد، فلا تظهر في المشهد. والأنهار أشرطة زخرفية تتبع
التضاريس (كما في المولّد القائم) ويُقال ذلك في التحذيرات.

| المعرّف | الخطورة | الافتراضي |
| --- | --- | --- |
| `water-contradiction` | حاجب | `keep-water` |
| `forest-without-trees` | حاجب | `no-trees` |
| `desert-dense-forest` | حاجب | `desert-oasis` |
| `island-without-water` | حاجب | `keep-sea` |
| `flat-and-mountainous` | حاجب | `mountains` |
| `river-negated-but-crossed` | حاجب | `road` |
| `hot-and-snow` | استشاري | `cold` |
| `anchor-missing-highground` | استشاري | `highest-point` |

**الحاجب** يوقف البناء كليّاً ويرمي `PlannerBlockedError` حتى يجيب المستخدم؛ الواجهة

**الاستشاري** يُحسم بخياره الافتراضي ويُذكر في الإشعارات، فلا يتوقف البناء أبداً بسببه.

## 7. خطة التنفيذ

16 خطوة مرتّبة طوبولوجياً: `validate-input` ← `resolve-terrain` ← `resolve-biomes` ←
`resolve-regions` ← `resolve-positions` ← `place-landmarks` ← `place-buildings` ←
`place-assets` ← `place-vegetation` ← `connect-paths` ← `add-water` ← `apply-materials`
← `apply-lighting` ← `apply-environment` ← `validate-scene` ← `report`.

- **ميزانية واحدة**: كل خطوة تأخذ حصتها من وعاء واحد = `MAX_WORLD_OBJECTS` (1500) −
  `RELATION_RESERVE` (48) − `WATER_RESERVE` (4)، فلا يلتزم المخطط أبداً بأكثر مما
  يتسع له المستند.
- **`preflight`** يحجب البناء عند: أبعاد أو دقة خارج الحد، سؤال حاجب بلا جواب، أصل
  غير موجود في المكتبة، أو دورة في التبعيات. ويحذّر (بلا حجب) عند: عنصر غير قابل
  للبناء، حيوانات، تجاوز السعة، علاقة `unsupported`، أو نهر بلا مستوى ماء.
- **`clampToBudget`** بأربع مراحل: تقليص النثر نسبياً ← تصفير ما تبقّى منه ← تقليص
  المجموعات المسماة (مع بقاء واحد من كل نوع) ← حذف العناصر (الدعامات قبل المعالم،
  ويُحفظ آخر مَعلم). كل تقليص يُعلن في إشعار عربي بالأرقام قبل وبعد.

## 8. الطبقات: حتمي مجاني + نموذج محلي اختياري

| الطبقة | المعرّف | متى |
| --- | --- | --- |
| المفسّر القائم | `local-heuristic-v1` | دائماً (طبقة صفر) |
| المحرّك القواعدي | `rules-v1` | دائماً، بلا إنترنت |
| نموذج لغة محلي مجاني | `local-llm` | فقط إذا فعّله المستخدم وتوفّر النموذج |

### تشغيل النموذج المحلي

```bash
python3 world-builder-server.py --port 8080 --llm-url http://127.0.0.1:11434/api/generate
# أو أي واجهة متوافقة مع OpenAI:
python3 world-builder-server.py --llm-url http://127.0.0.1:8080/v1/chat/completions --llm-timeout 45
```

بدون `--llm-url` يبقى المسار `/api/local-llm` معطلاً (404) ويعمل التطبيق كاملاً
بدون اتصال. الخادم **يرفض أي عنوان غير محلي** (`127.0.0.1`/`localhost`/`::1` فقط)،
بلا مفاتيح API وبلا إعادة توجيه، ويقيّد حجم الطلب والجواب.

### ما يُسمح للنموذج به

يُستشار فقط عن **النقص** (`enrichmentGaps`)، ويُطلب منه JSON صارم، ويُتحقق من جوابه
بـ`llmEnrichmentSchema` (strict) ثم يُرشَّح مرة أخرى في `mergeEnrichment`:

- يملأ: البيئة، شكل الأرض، الوقت، الكثافة، الأسلوب، الطقس، الطراز المعماري، ألوان
  المواد، المناطق، الحيوانات المعروفة، أسئلة استيضاحية **استشارية** فقط، واسم العالم
  ما دام بلا اسم.
- **لا يغيّر أبداً**: الأعداد، المواضع، العلاقات المحلولة، النفي، الميزانيات، أبعاد
  العالم (يقترح المقياس ويُرفض مع إشعار عربي)، ولا يقترح ما يناقض الوصف (بيئة أو
  شكل أرض غير متوافقين يُرفضان مع إشعار).
- إن تعذّر أو تأخر أو أجاب بهراء: يبقى المخطط على `rules` ويضيف إشعاراً عربياً، ولا
  يفشل الطلب أبداً.

## 9. الواجهة

في لوحة AI (`إعدادات العالم المتقدمة`):

- **المخطط المتقدم للعالم** (مفعّل افتراضياً): يفهم العلاقات المكانية والمقاييس
  والكثافة والأساليب والتعليمات السالبة، ويضع خطة تنفيذ كاملة ويسأل عند التناقض.
  إلغاء تفعيله يعيد المسار الكلاسيكي كما كان حرفياً.
- **نموذج لغوي محلي مجاني (اختياري)**: معطّل افتراضياً؛ يحتاج `--llm-url`.

أثناء التخطيط يظهر سطر المرحلة الحالية («حل القيود والأعداد والميزانية»…). وبعد البناء
تظهر بطاقة **خطة تنفيذ العالم**: ملخص عربي بسطر واحد، نتائج `preflight`، الخطوات
الـ16 بحالة كل خطوة وما أنتجته، و14 قسماً قابلاً للطي (الأبعاد، التضاريس، البيئات،
المناطق، المباني، العناصر، الحيوانات، المواد، الإضاءة، الجو، العلاقات، المواضع،
النفي، السعة). كل نصوصها عربية؛ لا يظهر معرّف داخلي ولا كلمة `undefined`.

مسار المكتبة/الصورة (المجسمات الجاهزة CC0) يستفيد من الخطة نفسها عبر
`applySpecToShell`: الأرض والماء والإضاءة والجو من المخطط، والمجسمات من مسارها القائم.
وأي تناقض حاجب يُسأل عنه **قبل** تنزيل أي مجسم.
