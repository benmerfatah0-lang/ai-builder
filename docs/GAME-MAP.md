## اقرأ الخريطة في ٣٠ ثانية

| | |
|---|---|
| **البداية** | أسفل الخريطة — حافّة الغابة، حيث يبدأ زعتر |
| **الطريق** | خطّ واحد يصعد: المزرعة ← الزراعة ← الحظائر ← قصر الحضيرة (أعلى الخريطة) |
| **المناطق الأساسية الثلاث** | ١ المزرعة · ٢ منطقة الزراعة · ٣ منطقة الحظائر |
| **الخاتمة** | قصر الحضيرة، داخل منطقة الحظائر (الزاوية الشمالية الغربية) |
| **البوسات** | ٢ رئيسي + ٢ اختياري + ١ نهائي = **٥** |
| **نقاط الحفظ** | **٦** (كلها على الطريق الرئيسي) |
| **الاختصارات** | **٣** تُغلق الحلقات بعد كل موت (مصعد الطاحونة، مِزلق الحبوب، نفق الثعلب) |

> أعلى / أسفل هنا هما أعلى وأسفل **ورقة الخريطة**، وليسا جهات العالم الحقيقية.
> الاتجاه المرسوم على الخريطة الورقية: الأعلى = شمال الحضيرة (القصر)، الأسفل = البداية.

## ١ — الفكرة في سطر

ثعلب جائع يقتحم مزرعة دجاج عظيمة، فيجدها محمية بخمسة أبطال من حيوانات الحضيرة نفسها.
اللعبة كوميديا سوداء لطيفة: زعتر لا يريد تدمير المزرعة — يريد فقط أن يتعشّى. والنهاية
ليست انتصارًا عسكريًا بل **مأدبة سلام** يقيمها الدجاج للثعلب.

**النوع:** Souls-like خفيف (Soulslite) — كمائن مدروسة، نقاط حفظ، اختصارات، وبوسات لها
مراحل ونوافذ عقاب. **الميزانية الحسّية:** أشكال كرتونية خشنة، ألوان مشبعة، ظلال قوية،
وحيوانات بحجم مبالغ فيه.

## ٢ — الهيكل: ثلاث مناطق + مقدمة + خاتمة

الخريطة مصممة كـ **Hub & Spoke**: طريق رئيسي واحد مزدحم يربط كل شيء، وحلقات جانبية
تُفتح بالاختصارات. هذا الشكل هو الأنسب لألعاب السولز لأن اللاعب يبني خريطة ذهنية سريعة
ويعود لنقاط الحفظ بسرعة بعد كل موت.

```
                 ▲ شمال (أعلى الخريطة)
   ┌───────────────────────────────────────────────┐
   │  👑 قصر الحضيرة        🐑 مرج الأغنام/حلبة الكباش│
   │      (الخاتمة)                                  │
   │  ═════════════════ النهر + الجسر ═══════════════ │
   │  🐓 حظائر الدجاج       🦆 بركة البط             │
   │                 ⚔️ مفرق الحظائر                 │
   │   ─────────────── منطقة ٣: الحظائر ───────────  │
   │                                                 │
   │   🌾 حقول + طاحونة      ⚔️ غُبار       🏠 بيت     │
   │   ── منطقة ٢: الزراعة ──   (الدراس)    المزرعة   │
   │                      🛒 السوق + البئر   ⚔️ صيّاح │
   │   ─────────────── منطقة ١: المزرعة ───────────  │
   │                                                 │
   │              🚪 البوابة   🌲 حافّة الغابة 🦊     │
   └───────────────────────────────────────────────┘
                 ▼ جنوب (بداية زعتر)
```

### المنطقة ٠ — حافّة الغابة (مقدمة تعليمية، بلا بوسات)
- درب عرعر مائل، مخيّم أم سليم (**الحلزونة** — نقطة حفظ وشروح)، والغراب سعد (**تاجر بذور**).
- تعلّم: الحركة، القفز، التمرّغ بالوحل، وتجنّب الفزّاعة الاستعراضية.
- سرّ صغير: **قبر الدجاجة المجهولة** (يمنح تعويذة دفاع +١ وتمهيدًا للحكاية).

### المنطقة ١ — المزرعة (ساحة البلدة)
بيت المزرعة، السوق، بئر الحوش، صومعة الحبوب، طاحونة الهواء، سقيفة الأدوات، وبيت الديك.
**أول بوسين**: غُبار (غربًا في ساحة الدراس) وصيّاح (عند ممرّ الديك جنوبًا).
هي «الواجهة» التي يعرض فيها التصميم قواعده: مساحة آمنة، ثم أول كمين، ثم أول أرينا.

### المنطقة ٢ — منطقة الزراعة (الحقول)
قطاعات قمح، دوّار شمس، خضار وشمندر، مخزن الجرن، صومعة الغلال، وطاحونة على الخور.
**بوس رئيسي**: غُبار الحصّاد على حدود الساحة الغربية عند ساحة الدراس (شِراع دوّار في المرحلة ٢).
الحقول تعمل كجيوب قتال وتسلّل، وتقطع خطوط الرؤية الطويلة — درس «اقرأ الأرض».

### المنطقة ٣ — منطقة الحظائر (أكثر منطقة مركّبة)
جنوب النهر: حظائر دجاج حرّة، مرج أغنام، حلبة كباش، بركة بط، اسطبل الماعز، شبكة مياه
وأنابيب ريّ. **بوسان اختياريان**: بطبوط على الجسر، ونطّاح في الحلبة. ثم درب طويل
غربًا يصعد عبر «ممرّ الحضيرة» إلى آخر نقطة حفظ.

### المنطقة ٤ — قصر الحضيرة (خاتمة داخل الحظائر)
فناء محصّن بسور حجري وبوابة بقفل ريشة، أعمدة وفوانيس، وعرش تبن.
**البوس النهائي**: كلوكزيلا (٣ مراحل). بعد الهزيمة: مشهد النهاية — مأدبة السلام.

## ٤ — البوسات الخمسة

### 🦃 غُبار — حصّاد الحقل (الديك الرومي)
- **الأرينا:** ساحة الدراس (أول أرينا)، دائرية، أشرعة الدراس على المحيط.
- **المراحل:** دورات مذراة ثلاثية ← غبار يعمي الرؤية + أشرعة دوّارة في المرحلة ٢.
- **الدرس التصميمي:** «بوّابة الإيقاع» — تعلّم المرور تحت الهجمة بدل الهروب للخلف.
- **المكافأة:** ريشة الحصاد (تفتح مصعد الطاحونة)، بذرة قوة +٢.

### 🐓 صيّاح — ديك الحوش المتغطرس
- **الأرينا:** حوش الديك — عمود مركزي وبالاتات قشّ.
- **المراحل:** صرخة تُبطئ اللاعب ← وثبات من العمود إلى الأرض ← نوبة غرور تستدعي دجاجات.
- **الدرسن:** «الصبر مقابل السرعة» — الأرينا صغيرة تُجبرك على الصدّ لا التدحرج.
- **المكافأة:** ريشة صيّاح (تفتح بوابة القصر!)، قدرة «الصيحة».

### 🦆 بطبوط — حارس الجسر الطيني (اختياري)
- **الأرينا:** الجسر نفسه — ٣ أمتار عرضًا، ألواح تنقلب، ماء ابتلاع.
- **الجديد:** المعركة كلها منصّة؛ السقوط يعيدك إلى فانوس الجسر (عقوبة عادلة).
- **المكافأة:** ريشة سباحة، حجر ترقية، خريطة أنابيب الريّ.

### 🐏 نطّاح — كبش الحلبة العجوز (اختياري)
- **الأرينا:** حلقة حجرية بلا دروع، أعمدة على المحيط.
- **الجديد:** الاندفاع هو كل شيء؛ الأعمدة الحجرية تحوّله إلى سلاحك.
- **المكافأة:** قرن الكبش، حجر ترقية كبير، دروع صوف.

### 👑 كلوكزيلا — ملكة الحضيرة (النهائي)
- **الأرينا:** حلقة العرش — أرضية عشّ متفتّحة، فوانيس معلّقة، كتاكيت في المرحلة ٢.
- **الجديد:** تركيب كل ما سبق: مساحة متغيّرة + وابل مقذوفات + نافذة عقاب ثابتة بعد كل وابل.
- **المكافأة:** البيضة الذهبية، تاج الدجاج، ومأدبة السلام.

> كل بوس له **صوت ولمعة قبل كل هجمة** — لا هجمات غير مرئية. وكل هجمة لها نافذة عقاب
> واحدة على الأقل، وكل معركة تُعلَّم مرتين قبل أن تُطلب.

## ٨ — ملاحظات التصميم (لماذا هذه الخيارات؟)

1. **الخطّي المُتشعّب، لا المفتوح.** Souls-like يحتاج قراءة سريعة: طريق رئيسي واحد
   بثلاث نقاط تفرّع، لا غابة من الطرق. التفرّعات كلها تُغلق على نفس الطريق.
2. **الحقول كجيوب.** كل قطاع زراعي محاط بسياج وله مدخلان فقط: يخلق قرارًا (اختصار
   مقابل كشف) بلا أسوار وهمية.
3. **الماء كحدود.** النهر يفصل المزرعة عن الحظائر ويُجبر اللاعب على نقطة عبور واحدة
   — الجسر — التي هي في الوقت نفسه أرينا اختيارية. حدود طبيعية بدل جدران غير مرئية.
4. **البوسات هي المحطات، لا العوائق.** كل بوس يفتح اختصارًا أو قدرة، فالقتال يقدّم
   الخريطة وليس العكس.
5. **لا قتال في الممرات الطويلة.** الممرّ الأخير إلى القصر خالٍ من الأعداء: صمت
   متعمّد قبل الخاتمة (وأيضًا مكان لاستعادة الأنفاس بعد الموت).
6. **الكوميديا في الحواشي.** خيّال فزّاعة يتكلّم، دودة تبيع التلميحات، دجاجات بلاط
   تتفرّج — الفكاهة لا تُعيق المسار الرئيسي أبدًا.

## ٩ — كيف ترى الخريطة؟

### أ) ملف واحد فقط — أسهل طريقة (لرئيس المشروع)

انقر مرتين على الملف:

**`map-preview.html`** (في جذر المشروع) ← ملف واحد، ٠٫٦ ميغابايت

> أو بنفس المحتوى: `docs/خريطة-زعتر.html` — ويُخدَم أيضًا على `/map-preview.html`.

هذا كل شيء. لا تثبيت، لا Node، لا خادم، لا إنترنت:

- **ابدأ من هنا:** افتحه بـ Chrome أو Safari أو Edge أو حتى على الجوّال.
- **كل شيء داخله:** الصور السبع مضغوطة ومدمجة، والخريطة الورقية SVG مضمّنة كنص،
  وملفات البوسات ونقاط الحفظ كلها نص عربي — لا يوجد أي ملف خارجي.
- **قابل للإرسال:** أرسله على واتساب أو البريد أو فلاشة، ويعمل عند الطرف الآخر كما هو.
- **للطباعة:** زرّ «🖨️ طباعة الخريطة الورقية» في الصفحة يطبع الورقة على A3 عموديًا.

> بلا إنترنت يعمل كل شيء؛ الخط العربيّ وحده يتحوّل إلى خط النظام — الشكل يبقى مقروءًا.

### ب) استكشف الخريطة بزعتر (تحكّم بسيط، بلا قتال)

**أسرع طريقة — رابط واحد بلا أي زرّ:**

```
http://localhost:5173/game-map.html?explore
```

هذا الرابط يفتحك **داخل الاستكشاف مباشرة**: تجد نفسك واقفًا بزعتر عند بوابة
المزرعة، جاهزًا للمشي. لا تُضغط أي زرّ ولا تُختار أي قائمة.

> من صفحة المعاينة الحيّة يكفي فتح الجذر `/` — يُحوّلك تلقائيًا إلى `?explore`.

**طريقة ثانية:** من الديوراما اضغط زرّ **«🦊 استكشف الخريطة بزعتر»** (أو مفتاح **E**).

| المفتاح | الوظيفة |
|---|---|
| `W A S D` أو الأسهم | المشي (بالنسبة لاتجاه الكاميرا) |
| `Shift` | جري |
| `Space` | قفز |
| `E` أو زرّ الخروج | خروج من الاستكشاف |
| `R` | العودة إلى نقطة البداية |

على الجوّال تظهر **عصا تحكّم** أسفل اليسار وثلاثة أزرار (قفز · جري · إعادة).

**ما يوجد في هذا الوضع:** كاميرا تتبع، حركة على تضاريس حقيقية، بطء عند خوض
النهر، شريط تقدّم من الغابة إلى القصر، وتنبيه كلما اقتربت من نقطة حفظ.

**ما لا يوجد عمدًا:** لا قتال، لا صحة، لا أعداء، لا ضرر — الهدف **اكتشاف**
المستوى والتحقق من إحساس المسار (نقطة اختناق الجسر، طول الممر الأخير إلى القصر)
قبل بناء اللعبة.

- انقر أي منطقة أو شعار بوس لقراءة ملفّ تصميمه.
- تبويبات الأعلى: **ديوراما** (ثلاثي الأبعاد) · **ورقية** (مخطط SVG) ·
  **ورقة التصميم** (كل النصوص).
- أزرار المناطق في الأعلى تنقلك مباشرة؛ و«جولة» تتجول تلقائيًا بين الأرينات.
- تعمل من الجوّال أيضًا (ودجت اللمس).

> ملاحظة: يلزم WebGL 2. على أجهزة بلا تسريع رسومات ستظهر شاشتان بديلتان
> (الورقية وورقة التصميم) وهذا مُتعمَّد: الخريطة تُقرأ دون ثلاثي الأبعاد.

### هـ) إعادة توليد كل شيء

```bash
npm run map:render        # صور الديوراما الخمس + النظرة العامة + من أعلى
npm run map:paper         # خريطة SVG الورقية + ملف TS المضمّن
npm run map:page          # الصفحة المحمولة (ملف واحد) + صفحة المجلد
npm run map:all           # الثلاثة معًا
npm test                  # سلامة بيانات الخريطة + فيزياء حركة زعتر
```

> **فحوصات سلامة الخريطة** (`src/game-map/mapData.test.ts`): تتأكد آليًا أن كل بوس
> له أرينا حقيقية داخل منطقته، وأن نقاط الحفظ على الطرق، وأن المباني والحقول لا
> تتراكب، وأن النهر محفور تحت منسوب الماء، وأن الحصون لا تغرق — أي تعديل مستقبلي
> على `data.ts` يكسر الخريطة يُكتشف قبل الرسم.
