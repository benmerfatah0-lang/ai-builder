# تشغيل الخريطة على أندرويد (Termux)

> **أسرع طريقة (بلا تثبيت أي شيء):** أرسل ملف `map-preview.html` (٦٦١ ك.ب) إلى هاتفك
> وافتحه بأي متصفح. كل الصور والخريطة الورقية مدمجة داخله، ويعمل بلا إنترنت.
> هذا يكفي لـ **قراءة الخريطة** كاملة.
>
> أما **المشي بزعتر في الديوراما** فيحتاج خادمًا — وهو ما يشرحه هذا الملف.

---

## ١) المتطلبات

| المطلوب | لماذا |
|---|---|
| Termux (من F-Droid، لا من Play) | إصدار Play قديم ولا يستقبل تحديثات الحزم |
| Node.js **20.19+** أو **22.12+** | يفرضه `engines` في `package.json` |
| ~٣٠٠ ميغابايت مساحة | `node_modules` + `dist` |

## ٢) التثبيت

```bash
pkg update && pkg upgrade -y
pkg install nodejs-lts git -y
termux-setup-storage        # للوصول إلى مجلد التنزيلات
node -v                     # تأكد أنه 20.19+ أو 22.12+
```

```bash
git clone https://github.com/benmerfatah0-lang/ai-builder.git
cd ai-builder
npm run install:termux
```

> **مهم — لماذا `install:termux` وليس `npm install`:**
> المشروع يستخدم `sharp` لتوليد صفحة الـHTML المجمّعة، وهي حزمة أصلية **بلا نسخة
> أندرويد** (٢٥ حزمة منصّة، لا واحدة لأندرويد). الأمر أعلاه ينفّذ
> `npm install --ignore-scripts`، فيُثبّت كل شيء ويترك `sharp` بلا مكتبتها الأصلية —
> وهذا لا يضرّ لأن **التطبيق لا يستوردها إطلاقًا**؛ تُستخدم فقط في `npm run map:page`.

> ⚠️ **لا تستخدم `--omit=optional`.** جرّبتها: تحذف `rollup` و`esbuild` الأصليين
> (لأنهما optional داخل vite)، فيفشل الخادم بخطأ `MODULE_NOT_FOUND` عند الإقلاع.

## ٣) التشغيل

```bash
npm run dev:termux
```

سيطبع:

```
➜  Local:   http://localhost:5173/
```

افتح في متصفح الهاتف:

```
http://localhost:5173/game-map.html?explore
```

تهبط مباشرة **بزعتر عند بوابة المزرعة**. التحكّم على الجوّال: **عصا تحكّم أسفل
اليسار** + أزرار القفز/الجري/الإعادة.

### فتحها من حاسوب على نفس شبكة الواي فاي

`vite` يستمع على `0.0.0.0`، فيطبع أيضًا عنوان الشبكة:

```
➜  Network: http://192.168.x.x:5173/
```

افتح ذلك العنوان من أي جهاز على نفس الشبكة.

## ٤) بناء نسخة ثابتة (بلا خادم)

```bash
npm run build:termux
```

الناتج في `dist/` (١٫٥ م.ب). يمكنك:

- نسخه إلى استضافة ثابتة (GitHub Pages، Netlify Drop) — يعمل كما هو.
- تشغيله محليًا بخادم بسيط:
  ```bash
  cd dist && python -m http.server 8000
  ```
  ثم `http://localhost:8000/game-map.html?explore`

> `npm run build` العادي يشغّل `tsc --noEmit` أولًا — أبطأ وأثقل على الهاتف.
> استخدم `build:termux` إن أردت السرعة فقط.

## ٥) مشاكل متوقعة

| المشكلة | الحل |
|---|---|
| `Unsupported engine` | نسخة Node قديمة: `pkg install nodejs-lts` أو `pkg upgrade` |
| شاشة سوداء في الاستكشاف | الجهاز/المتصفح بلا WebGL 2 — يعرض التطبيق الخريطة الورقية ورسالة تلقائيًا |
| `ENOSPC` | مساحة ممتلئة: احذف `dist/` و`npm cache clean --force` |
| بطء شديد | طبيعي على الهواتف القديمة؛ الديوراما ~١٦٠ ألف مثلث |
| `sharp` يفشل بالتثبيت | تجاهله — غير مطلوب للتطبيق. أو ثبّت بـ `--ignore-scripts` |
| المتصفح لا يفتح `localhost` | اكتب `http://127.0.0.1:5173` أو استخدم عنوان الشبكة |

## ٦) ما تم التحقق منه فعليًا

اختبرت السيناريو كاملًا على نسخة نظيفة من git (`git archive` ← `npm install
--ignore-scripts` ← تشغيل):

- ✅ التثبيت: `added 147 packages in 4s`
- ✅ الخادم يقلع: `VITE v7.3.7 ready in 160 ms`
- ✅ `/game-map.html?explore` ← **200**، و`GameMap.tsx` ← **200**، و`player.ts` ← **200**
- ✅ `vite build` ← **✓ built in 4.17s** بحجم `dist` = ١٫٥ م.ب
- ✅ `dist/` يعمل كموقع ثابت (`/game-map.html` ← 200)

**لم أستطع التحقق منه:** تشغيل Termux نفسه (البيئة هنا لينكس x64، لا أندرويد).
تحققت من المنطق على نفس معمارية الحزم: `esbuild` و`rollup` **يوفّران حزم أندرويد
arm64 رسميًا**، و`sharp` هي الوحيدة الغائبة — وهي غير مستخدمة في التطبيق.
