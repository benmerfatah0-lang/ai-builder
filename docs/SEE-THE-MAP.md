# أسهل طريقة لرؤية الماب

> **الحلّ الأسرع:** افتح الملف **`map-3d.html`** بضغطة مزدوجة.
> لا خادم، لا تنصيب، لا إنترنت. الماب ثلاثي الأبعاد الحقيقي كاملاً في ملف واحد.

---

## ١) طريقة الضغطة المزدوجة — ملف واحد (الأفضل)

الملف: **`map-3d.html`** في جذر المشروع (حجمه ~٢ م.ب، يحتوي الماب + سبع صور مضمّنة).

**على الكمبيوتر:**

1. نزّل الملف `map-3d.html` من المستودع.
2. اضغط عليه **ضغطة مزدوجة**.
3. سيفتح في متصفّحك مباشرة وتظهر الديوراما ثلاثية الأبعاد.

**على الأندرويد — تنبيه حاسم:**

مجرّد الضغط على الملف من تطبيق «التنزيلات» أو «الملفات» يفتحه بمسار
`content://media/external/...`، و**كروم يمنع تنفيذ JavaScript في هذا المسار**.
النتيجة: يظهر عنوان الصفحة فقط وجسمها أبيض فارغ.

لهذا صار الملف يحتوي **معرض الصور السبعة مباشرة داخل الصفحة**، بلا أي JavaScript.
فأنت سترى الخريطة كاملة في كل الأحوال:

- **إن عُرضت الصور** (الحالة المعتادة) → هذا هو الماب. سبعة مناظر بجودة عالية.
- **إن أردت الماب التفاعلي** (تدوير الكاميرا والاستكشاف بزعتر) فافتح الملف
  بطريقة تمنحه مسار `file://` بدل `content://`:
  1. نزّل تطبيق **Total Commander** (مجاني) أو استخدم **Files by Google**.
  2. فيه: اضغط الملف مطوّلاً ← **Open with** ← **Chrome**.
  3. أو الأسهل: افتحه من داخل **Chrome** مباشرة:
     `⋮` ← **Downloads** ← اضغط اسم الملف.

> **لماذا لا يعمل الماب التفاعلي من «التنزيلات» مباشرة؟**
> لأن المتصفح يعطيه مسار `content://` وليس `file://`، وهذا قرار أمني في أندرويد
> لا يمكن لأي ملف HTML تجاوزه. لهذا جعلنا الصور تعمل دائماً كحلّ احتياطي.

> هذا الملف يحتوي **كل شيء داخله**: كود React، ومحرّك Three.js، والأنماط، والأيقونة.
> لذلك يعمل بلا شبكة وبلا خادم وبلا `npm`. يحتاج فقط متصفّحاً يدعم WebGL 2
> (كل متصفّح حديث يدعمه). إن لم يجد WebGL تعرض الصفحة الخريطة الورقية تلقائياً.

### ما الذي ترى بعد الفتح؟

- **🏔️ ديوراما** — الماب ثلاثية الأبعاد نفسها. اسحب بالفأرة لتدوير الكاميرا،
  وبالعجلة للتكبير. الأزرار أعلى الصفحة تنقلك بين المناظر:
  **نظرة عامة / البداية / المزرعة / الزراعة / الحظائر / القصر**.
- **🧭 استكشف بزعتر** (من زر «جولة» أو `?explore`) — تمشي بالثعلب زعتر في الماب:
  `W A S D` أو الأسهم للحركة، `Shift` للجري، `Space` للقفز، `R` للإعادة، `E` للخروج.
  على الهاتف يظهر عصا تحكّم لمسية أسفل الشاشة.
- **🗞️ ورقية** — النسخة الورقية المسطّحة بالمناطق والمسارات.

## ٢) المعاينة الحيّة — تنبيه مهم

خادم التطوير يعمل داخل صندوق مؤقّت، ولكل جلسة **صندوق جديد ورابط جديد**.
لذلك **أي رابط معاينة قديم سيتوقّف عن العمل** ويعطيك:

> `502 BAD GATEWAY` / `SANDBOX NOT FOUND`

هذا **ليس** عطلاً في الماب — بل انتهت صلاحية ذلك الصندوق. الرابط الصالح هو
الذي تراه في لوحة المعاينة الحيّة بجانب اسم العملية الآن. إن لم يظهر،
استخدم الطريقة (١) أعلاه أو (٣) أدناه، وكلتاهما لا تعتمد على أي صندوق.

## ٣) التحميل الدائم من GitHub (لا ينكسر أبداً)

الملف محفوظ في المستودع، فرابط تحميله ثابت ما دام المستودع موجوداً:

1. افتح صفحة الملف على GitHub:
   <https://github.com/benmerfatah0-lang/ai-builder/blob/arena/a93f766d-ai-builder/map-3d.html>
2. اضغط زرّ **Download raw file** (أيقونة التنزيل أعلى يمين محتوى الملف).
3. افتح الملف الذي نزّلته بضغطة مزدوجة.

بديل أسرع على الهاتف: من نفس الصفحة اضغط **⋮ ← Download**، أو استخدم
<https://github.com/benmerfatah0-lang/ai-builder/raw/arena/a93f766d-ai-builder/map-3d.html>
— سيبدأ التنزيل مباشرة (بعض المتصفّحات تحذّفك من تنزيل ملف HTML؛ اختر «تنزيل»).

## ٤) من داخل المشروع (للمطوّرين)

```bash
npm install
npm run dev:map      # ثم افتح http://localhost:5173
```

## ٥) لقطة ثابتة بلا أي تفاعل

الملف `map-preview.html` (في الجذر) هو صفحة صور ثابتة — سبع لقطات عالية الجودة
للمناظر السبعة، مضمَّنة داخل الملف. مناسب للمشاركة والمراجعة السريعة، لكنه
**لا** يتيح تدوير الكاميرا ولا الاستكشاف.

---

## إعادة بناء الملف أحادي الملف

```bash
npm run build:single
```

يُنتج `map-3d.html` من جديد. السكربت `scripts/buildSingleFile.py` يدمج
حزمة vite الواحدة داخل صفحة HTML واحدة، ويحوّل الوحدات إلى صيغة كلاسيكية لأن
`file://` يرفض `type="module"`.
